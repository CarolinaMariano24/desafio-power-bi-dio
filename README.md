# Desafio Power BI — DIO

## 📊 Sobre o projeto

Projeto desenvolvido como parte do desafio prático de Power BI da DIO, com o objetivo de aplicar os conhecimentos adquiridos durante o curso na criação de um relatório interativo e na análise de dados de vendas e lucratividade.

O projeto foi desenvolvido a partir da base de dados Financial Sample, utilizando o Power BI Desktop.

## 🎯 Objetivos

- Reproduzir análises apresentadas durante o curso;
- Criar visualizações interativas para análise de dados;
- Explorar indicadores de vendas, unidades vendidas, descontos, custos e lucro;
- Desenvolver uma página adicional de forma independente, conforme solicitado no desafio.

## 📈 Análises desenvolvidas

O relatório contém três páginas:

### Página 1 — Visão Geral

- Total de vendas;
- Unidades vendidas;
- Total de descontos;
- Total de COGS;
- Vendas por mês;
- Vendas por segmento;
- Vendas por produto;
- Vendas por país;
- Filtro por período.

### Página 2 — Report de Lucro Detalhado

- Análise de lucro por diferentes dimensões;
- Árvore de decomposição;
- Lucro por segmento;
- Lucro por trimestre;
- Análises complementares de lucratividade.

### Página 3 — Análise de Vendas e Lucro

Página criada de forma independente para o desafio, contendo:

- Vendas e unidades vendidas por país;
- Lucro por país;
- Lucro por segmento.
